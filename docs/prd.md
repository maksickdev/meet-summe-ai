**Название проекта (рабочее): summe

### 1. Общая идея и ценность продукта

Лёгкое, приватное, кросс-платформенное десктопное приложение, которое:

- Захватывает **системный звук + микрофон** (как встроенный рекордер Zoom / Teams)
- Записывает встречи, созвоны, лекции, подкасты, голосовые заметки
- Автоматически (или по кнопке) отправляет аудио в **Google Gemini** → получает качественную транскрипцию + интеллектуальную суммаризацию
- Форматирует результат в красивый **Markdown**-файл (с заголовками, списками дел, выделением ключевых моментов, таймкодами)
- Хранит всё **локально** (с опцией облачного бэкапа позже)
- Работает **в фоне** через иконку в трее, минимально потребляет ресурсы
- В будущем — SaaS-версия с подпиской (облачная обработка, командные заметки, поиск по всем записям, интеграции)

Целевая аудитория 2026 года:
- Фрилансеры / удалёнщики / менеджеры (много встреч)
- Студенты / преподаватели (лекции, семинары)
- Журналисты, подкастеры, исследователи
- Люди, которым важна **приватность** (нет ботов в звонке, данные не уходят третьим лицам кроме Gemini API)

### 2. Ключевые фичи (MVP → 1.0 → будущие)

**MVP (первые 2–4 месяца разработки)**

- Запись системного аудио + микрофона одновременно (loopback)
- Пауза / возобновление / остановка записи
- Выбор папки для сохранения .m4a / .wav / .mp3
- Одна кнопка «Summarize with Gemini» → транскрипция + краткое summary + action items
- Автосохранение в Markdown (с таймкодами, speaker labels если Gemini даст)
- Tray icon + глобальные хоткеи (начать/остановить запись)
- Скрытие окна при закрытии → работа в фоне
- Простой UI: главное окно — плеер + список записей + кнопка summarize

**Версия 1.0 (добавляем polish)**

- Выбор качества записи (low/medium/high)
- Автоматическое определение языка (или выбор)
- Шаблоны промптов для Gemini (meeting notes / lecture / brainstorming / interview)
- Редактирование / копирование / экспорт md → pdf / notion / obsidian
- Уведомления о завершении обработки
- Темная / светлая тема + авто
- Автозапуск при старте ОС (опционально)
- Прогресс-бар / статус в трее (запись идёт → мигающий красный круг)

**Пост-1.0 / SaaS-ориентир**

- Локальный vs облачный режим (Gemini API ключ → свой / наш прокси-сервер)
- Поиск по всем заметкам (full-text + semantic)
- Теги / проекты / папки
- Командный доступ (shared workspace)
- Интеграции: Zoom/Teams/Google Meet calendar → авто-запись
- Мобильное приложение (Tauri Mobile)
- Подписка: бесплатный лимит (10 записей/мес) → Pro (неограниченно + приоритет Gemini)

### 3. Технический стек (окончательный выбор)

- **Frontend**: React 19 + TypeScript + Vite
- **UI-библиотека**: shadcn/ui / Radix UI + Tailwind CSS
- **Markdown rendering**: react-markdown + remark-gfm + rehype-highlight
- **Desktop framework**: Tauri 2.x (Rust backend)
- **Запись аудио**: Rust-библиотеки cpal + ringbuf (или symphonia для кодирования)
  - Альтернатива: tauri-plugin с кастомным Rust-модулем
- **Gemini интеграция**: @google/generative-ai (Node) через IPC или reqwest в Rust
- **Хранение**: tauri-plugin-store / fs (локальные .json для метаданных + папка с аудио/md)
- **Глобальные хоткеи**: tauri-plugin-global-shortcut
- **Tray + notifications**: встроенные в Tauri 2 (tray-icon + notification)
- **Динамическая иконка в трее**: TrayIconBuilder + разные .png (idle / recording / processing)

### 4. Пользовательский флоу (основной сценарий)

1. Пользователь запускает приложение → видит главное окно или сразу сворачивает в трей
2. Перед встречей / звонком → нажимает горячую клавишу или кнопку «Start Recording»
3. Окно скрывается → в трее появляется иконка с красным индикатором + таймер
4. Встреча проходит → звук пишется в RAM → по остановке сохраняется на диск
5. Автоматически (или вручную) → аудио → Gemini → приходит Markdown
6. Открывается предпросмотр: заголовок, ключевые моменты, todo-лист, полная транскрипция
7. Пользователь редактирует / копирует / сохраняет / делится

### 5. Монетизация и путь к SaaS

- Бесплатная версия: локальная запись + Gemini (свой API-ключ, лимит по токенам)
- Pro-подписка ($4–9/мес): 
  - Неограниченная обработка
  - Облачное хранение / поиск
  - Приоритетные модели Gemini
  - Командные фичи
- Enterprise: self-hosted прокси + on-prem Gemini (через Vertex AI)

### 6. Риски и как их минимизировать

- **Доступ к системному аудио** → на macOS нужно разрешение «Screen Recording», на Windows — может потребоваться виртуальный кабель в редких случаях
- **Gemini стоимость** → показывать пользователю расход токенов + лимит в бесплатной версии
- **Точность транскрипции** → несколько шаблонов промптов + возможность перегенерации
- **Linux-нюансы** (PulseAudio vs PipeWire) → тестировать на Ubuntu / Fedora / Arch
- **Размер бандла** → держать < 20 МБ (Tauri это позволяет)
